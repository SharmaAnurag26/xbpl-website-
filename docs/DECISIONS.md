# Decisions log

Short records of choices that aren't obvious from the code. Newest last.

## Phase A: foundation

| #   | Decision                                                                                                                                                  | Why                                                                                                                                                                                                                                                                                                                                                                                |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | **Next.js 16.3.8, React 19.2.8, Tailwind 4.3, TypeScript 5.9** (not TS 7)                                                                                 | TS 7 is the native Go port; Next's type-check pipeline is validated against TS 5.x. `create-next-app@16.3.8` also pins `typescript@^5` and `eslint@^9`.                                                                                                                                                                                                                            |
| D2  | pnpm installed globally via npm                                                                                                                           | `corepack enable` failed with EPERM (writes to `C:\Program Files\nodejs`). `packageManager` is pinned in package.json, so Vercel uses the same version.                                                                                                                                                                                                                            |
| D3  | **Contrast-safe token variants** (`brand-text #0663d4`, `muted #56667e`, button gradient `#0663d4 → #0874b0`)                                             | The original values fail WCAG AA for small text (see ANALYSIS §2). `pnpm contrast` checks every pairing the design uses. Cyan moves to glows, focus rings on dark, and display text.                                                                                                                                                                                               |
| D4  | **Static CSP with `'unsafe-inline'` scripts**, no nonces                                                                                                  | Nonces force every page into dynamic rendering, which hurts TTFB/LCP and the Lighthouse targets. Next's experimental SRI still requires inline RSC payload scripts. The site has no user-generated HTML; `object-src 'none'`, `base-uri 'self'`, `form-action 'self'`, and `frame-ancestors 'none'` still apply. Analytics origins are added only for the provider that's enabled. |
| D5  | **Logo rebuilt as geometry in `lib/brand/logo.ts`** and rendered by one `<Logo>` component; `pnpm icons` renders the same component to static SVG/PNG/ICO | One source of truth. Variants (`color`, `on-dark`, `mono-white`) are separate paints, not CSS filters. The tagline is drawn with strokes, so it never depends on a font. It's a faithful recreation, not the original artwork: replace it if the client has a master vector.                                                                                                       |
| D6  | **Image slots** (`lib/images.ts`) + generated manifest + CSS/SVG fallback art                                                                             | Pages look finished before photography exists, with no 404s and no layout shift. Dropping `public/images/<slot>.webp` is the whole workflow. `docs/IMAGE_BRIEF.md` is generated from the same registry.                                                                                                                                                                            |
| D7  | **Reveal/CountUp use `motion` (`inView` + `motion/mini` animate)** instead of `motion/react` components                                                   | The server HTML is always fully visible. Elements are hidden only after hydration and only if they're below the fold, so there's no blank page without JS and no LCP penalty. The mini/WAAPI animator keeps the client bundle small.                                                                                                                                               |
| D8  | **Insights filter**: server-rendered cards passed as React nodes to a small client `CategoryTabs`                                                         | The icon map and image logic stay on the server, and the page stays fully static. `?category=` is synced with `history.replaceState`.                                                                                                                                                                                                                                              |
| D9  | **Native `<select>`** for the contact form; **Radix Dialog** for the mobile drawer                                                                        | A native select is the most accessible option and works without JS. Dialog provides the focus trap, Escape handling, and focus return.                                                                                                                                                                                                                                             |
| D10 | Tech partner "logos" render as **neutral text** until official marks are supplied (`src` field)                                                           | Vendor marks are trademarks. Usage needs the vendor's brand guidelines or partner status.                                                                                                                                                                                                                                                                                          |
| D11 | `/styleguide` is **development-only** (404 in production, `noindex`)                                                                                      | It's a component gallery for development; a test asserts it isn't exposed.                                                                                                                                                                                                                                                                                                         |
| D12 | The footer year is computed at build time                                                                                                                 | Pages are static; any deploy refreshes it.                                                                                                                                                                                                                                                                                                                                         |
| D13 | `@next/mdx` with `remark-frontmatter` (strips YAML) + `gray-matter` (reads it)                                                                            | `remark-mdx-frontmatter` was dropped as unnecessary. Plugins are passed as strings, as Turbopack requires.                                                                                                                                                                                                                                                                         |

## Redesign: dark editorial look (requested 2026-10-03, reference: accenture.com)

| #   | Decision                                                                                                                                                                                                                 | Why                                                                                                                                                                     |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D17 | Adopted the reference site's **design language**: black canvas, one neutral grotesk at medium weight, oversized titles, portrait featured-card grid, staggered colour tiles, numbered editorial lists, full-bleed bands. | Requested by the client. Applied site-wide through semantic tokens (`canvas`, `surface`, `ink`, `muted`, `line`) so components stayed reusable.                         |
| D18 | **Kept XBPL's own identity**: blue/cyan gradient, logo, copy and page structure. Did **not** use Accenture's purple or ">" mark.                                                                                         | Those are another company's brand assets; copying them would make XBPL look like Accenture and create trade-dress risk.                                                 |
| D19 | **Inter only** (Sora removed from pages; still used inside generated OG images).                                                                                                                                         | Matches the single-typeface editorial style and removes one web-font download.                                                                                          |
| D20 | **Generated artwork** for every image slot (`pnpm art`, `pnpm banner`): ribbons, orbs, isometric blocks, data mesh, radar rings, dawn skyline.                                                                           | The image-led layout needs imagery. Real photography dropped into `public/images/` replaces any piece; the generator never overwrites existing files without `--force`. |
| D21 | Small-text blue on black is `#6cb4ff`; solid brand tiles use `#0663d4`; cyan tiles carry black text.                                                                                                                     | Keeps every text/background pair at WCAG AA (`pnpm contrast`).                                                                                                          |

## Gen Z refresh (requested 2026-10-04; competitors reviewed: TimesPro, SSDN Tech, Clarinet)

| #   | Decision                                                                                                                                                                                                                                                             | Why                                                                                                                                                                                                 |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D22 | Competitor sites were used for **structure ideas only** (learning formats, technology catalogue, FAQ, social proof, ticker). All copy is original.                                                                                                                   | Copying competitors' text is copyright infringement and duplicate content also hurts SEO.                                                                                                           |
| D23 | **Real 3D visuals rendered offline** (`pnpm render3d`): three.js in headless Chromium → trimmed transparent WebP stickers (20–50 KB each), sizes in `lib/stickers.json`.                                                                                             | Gives the glossy 3D look with zero runtime cost (no WebGL or 3D library shipped). The hero X is extruded from the real logo geometry.                                                               |
| D24 | Gen Z layer: volt accent `#d4ff3a` (black text only), pill buttons, rounder radii, bento grid, infinite tech ticker, rotating badge, grain, floating stickers.                                                                                                       | Requested vibe; all motion stops under `prefers-reduced-motion`.                                                                                                                                    |
| D25 | **Client logos and testimonials sections exist but are empty and hidden.**                                                                                                                                                                                           | Never publish invented social proof. Add real, approved items in `content/pages/home.ts` and they appear automatically.                                                                             |
| D26 | FAQ uses native `<details>`; answers only restate what the site already says.                                                                                                                                                                                        | Accessible with zero JS; no new claims.                                                                                                                                                             |
| D27 | **Supplied illustrations go on cards only** (course cards, article covers, the learners panel), never in page heroes. Originals live in `assets/illustrations/`; `pnpm illustrations` crops them per slot; `pnpm art` and `pnpm photos` never overwrite those slots. | Heroes fade their image into the dark canvas, which washes out white-background art. On cards the art sits in a clean frame, and it tells the courses apart better than near-identical code photos. |
| D28 | **Page banners use real CC0 photos** (Commons/Unsplash mirrors and rawpixel's public-domain set via Openverse), fetched by `pnpm photos`. rawpixel images use the 1024px API link only.                                                                              | rawpixel's larger public renditions carry a watermark. The banners fade into the dark canvas, so 1024px is sharp enough there.                                                                      |
