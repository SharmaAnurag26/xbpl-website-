# Decisions log

Short records of choices that aren't obvious from the code. Newest last.

## Phase A: foundation

| #   | Decision                                                                                                                                                  | Why                                                                                                                                                                                                                                                                                                                                                                                |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | **Next.js 16.3.8, React 19.2.8, Tailwind 4.3, TypeScript 5.9** (not TS 7)                                                                                 | TS 7 is the native Go port; Next's type-check pipeline is validated against TS 5.x. `create-next-app@16.3.8` also pins `typescript@^5` and `eslint@^9`.                                                                                                                                                                                                                            |
| D2  | pnpm installed globally via npm                                                                                                                           | `corepack enable` failed with EPERM (writes to `C:\Program Files\nodejs`). `packageManager` is pinned in package.json, so Vercel uses the same version.                                                                                                                                                                                                                            |
| D3  | **Contrast-safe token variants** (`brand-text #0663d4`, `muted #56667e`, button gradient `#0663d4 → #0874b0`)                                             | The original values fail WCAG AA for small text (see ANALYSIS §2). `pnpm contrast` checks every pairing the design uses. Cyan moves to glows, focus rings on dark, and display text.                                                                                                                                                                                               |
| D4  | **Static CSP with `'unsafe-inline'` scripts**, no nonces                                                                                                  | Nonces force every page into dynamic rendering, which hurts TTFB/LCP and the Lighthouse targets. Next's experimental SRI still requires inline RSC payload scripts. The site has no user-generated HTML; `object-src 'none'`, `base-uri 'self'`, `form-action 'self'`, and `frame-ancestors 'none'` still apply. Analytics origins are added only for the provider that's enabled. |
| D5  | **Logo rebuilt as geometry in `lib/brand/logo.ts`** and rendered by one `<Logo>` component; `pnpm icons` renders the same component to static SVG/PNG/ICO | One source of truth. Variants (`color`, `on-dark`, `mono-white`) are separate paints, not CSS filters. The tagline is drawn with strokes, so it never depends on a font. It's a faithful recreation, not the original artwork: replace it if the client has a master vector.                                                                                                       |
| D6  | **Image slots** (`lib/images.ts`) + generated manifest + CSS/SVG fallback art                                                                             | Pages look finished before photography exists, with no 404s and no layout shift. Dropping `public/images/<slot>.webp` is the whole workflow. `docs/IMAGE_BRIEF.md` is generated from the same registry.                                                                                                                                                                            |
| D7  | **Reveal/CountUp use `motion` (`inView` + `motion/mini` animate)** instead of `motion/react` components                                                   | The server HTML is always fully visible. Elements are hidden only after hydration and only if they're below the fold, so there's no blank page without JS and no LCP penalty. The mini/WAAPI animator keeps the client bundle small.                                                                                                                                               |
| D8  | **Insights filter**: server-rendered cards passed as React nodes to a small client `CategoryTabs`                                                         | The icon map and image logic stay on the server, and the page stays fully static. `?category=` is synced with `history.replaceState`.                                                                                                                                                                                                                                              |
| D9  | **Native `<select>`** for the contact form; **Radix Dialog** for the mobile drawer                                                                        | A native select is the most accessible option and works without JS. Dialog provides the focus trap, Escape handling, and focus return.                                                                                                                                                                                                                                             |
| D10 | Tech partner "logos" render as **neutral text** until official marks are supplied (`src` field)                                                           | Vendor marks are trademarks. Usage needs the vendor's brand guidelines or partner status.                                                                                                                                                                                                                                                                                          |
| D11 | `/styleguide` is **development-only** (404 in production, `noindex`)                                                                                      | It's a component gallery for development; a test asserts it isn't exposed.                                                                                                                                                                                                                                                                                                         |
| D12 | The footer year is computed at build time                                                                                                                 | Pages are static; any deploy refreshes it.                                                                                                                                                                                                                                                                                                                                         |
| D13 | `@next/mdx` with `remark-frontmatter` (strips YAML) + `gray-matter` (reads it)                                                                            | `remark-mdx-frontmatter` was dropped as unnecessary. Plugins are passed as strings, as Turbopack requires.                                                                                                                                                                                                                                                                         |
